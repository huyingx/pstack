# pstack

pstack provides engineering workflows as skills. This glossary distinguishes an individual workflow from the bundle and its installation source.

## Language

**pstack skill**:
An individual pstack workflow or principle that an agent can follow.
_Avoid_: pstack command, pstack plugin

**pstack plugin**:
The installable bundle of pstack skills.
_Avoid_: pstack skill, pstack marketplace

**pstack marketplace**:
The catalog that offers the pstack plugin for installation.
_Avoid_: pstack plugin, pstack skill collection
